
# 水质监测站运维检查管理系统 - 问答对

## 1. 任务统计相关

### 问题 (Q)：统计本周的任务情况

**回答 (A)：**

1. **确定时间范围**：根据当前时间计算本周的开始时间（周一0点）和结束时间（周日23:59:59），使用 `plan_dt` 字段进行时间范围查询。

2. **统计各状态任务数量**：

```sql
SELECT 
    COUNT(*) AS '任务总数',
    COUNT(CASE WHEN task_status = 'CLAIMING' THEN 1 END) AS '待认领',
    COUNT(CASE WHEN task_status = 'PENDING' THEN 1 END) AS '待处理',
    COUNT(CASE WHEN task_status = 'IN_PROGRESS' THEN 1 END) AS '处理中',
    COUNT(CASE WHEN task_status = 'APPROVING' OR task_status = 'COMPLETED' THEN 1 END) AS '已完成'
FROM task_info
WHERE state = 0
    AND plan_dt >= '2026-03-30 00:00:00'
    AND plan_dt <= '2026-04-05 23:59:59'
```

3. **按日期统计任务完成情况**：

```sql
SELECT 
    DATE_FORMAT(plan_dt, '%Y-%m-%d') AS '日期',
    COUNT(*) AS '任务总数',
    COUNT(CASE WHEN task_status = 'COMPLETED' THEN 1 END) AS '已完成',
    COUNT(CASE WHEN task_status != 'COMPLETED' THEN 1 END) AS '未完成'
FROM task_info
WHERE state = 0
    AND plan_dt >= '2026-03-30 00:00:00'
    AND plan_dt <= '2026-04-05 23:59:59'
GROUP BY DATE_FORMAT(plan_dt, '%Y-%m-%d')
ORDER BY DATE_FORMAT(plan_dt, '%Y-%m-%d')
```

4. **统计现场运维检查得分和异常项**：

```sql
SELECT 
    ti.id AS '任务ID',
    ti.site_name AS '站点名称',
    ii.score AS '得分',
    COUNT(ai.id) AS '异常项总数'
FROM task_info ti
INNER JOIN inspect_info ii ON ti.id = ii.task_id 
    AND ii.state = 0 
    AND ii.inspect_type = 'OPS'
LEFT JOIN abnormal_inspect ai ON ai.task_id = ti.id 
    AND ai.inspect_id = ii.id 
    AND ai.inspect_type = 'OPS' 
    AND ai.state = 0
WHERE ti.state = 0
    AND ti.plan_dt >= '2026-03-30 00:00:00'
    AND ti.plan_dt <= '2026-04-05 23:59:59'
GROUP BY ti.id, ti.site_name, ii.score
ORDER BY ii.score DESC
```

## 2. 异常项相关

### 问题 (Q)：统计本月各站点的异常项整改情况

**回答 (A)：**

```sql
SELECT 
    ti.site_id AS '站点ID',
    ti.site_name AS '站点名称',
    COUNT(ai.id) AS '异常项总数',
    COUNT(CASE WHEN ai.abnormal_status = 'TO_IMPROVE' THEN 1 END) AS '待整改',
    COUNT(CASE WHEN ai.abnormal_status = 'IMPROVING' THEN 1 END) AS '整改中',
    COUNT(CASE WHEN ai.abnormal_status = 'IMPROVED' THEN 1 END) AS '已整改',
    COUNT(CASE WHEN ai.abnormal_status = 'OVERDUE_IMPROVE' THEN 1 END) AS '超期整改',
    COUNT(CASE WHEN ai.abnormal_status = 'CLOSED' THEN 1 END) AS '已关闭'
FROM abnormal_inspect ai
INNER JOIN task_info ti ON ai.task_id = ti.id 
    AND ti.state = 0
WHERE ai.state = 0
    AND ai.created_dt >= '2026-05-01 00:00:00'
    AND ai.created_dt <= '2026-05-31 23:59:59'
GROUP BY ti.site_id, ti.site_name
ORDER BY COUNT(ai.id) DESC
```

## 4. 站点相关

### 问题 (Q)：统计各站点的任务完成率

**回答 (A)：**

```sql
SELECT 
    ti.site_id AS '站点ID',
    ti.site_name AS '站点名称',
    COUNT(*) AS '任务总数',
    COUNT(CASE WHEN ti.task_status = 'COMPLETED' THEN 1 END) AS '已完成数',
    ROUND(COUNT(CASE WHEN ti.task_status = 'COMPLETED' THEN 1 END) * 100.0 / COUNT(*), 2) AS '完成率(%)'
FROM task_info ti
WHERE ti.state = 0
    AND ti.plan_dt >= '2026-01-01'
    AND ti.plan_dt <= '2026-12-31'
GROUP BY ti.site_id, ti.site_name
ORDER BY COUNT(CASE WHEN ti.task_status = 'COMPLETED' THEN 1 END) * 100.0 / COUNT(*) DESC
```

## 5. 检查人员相关

### 问题 (Q)：查询检查人员本月的任务完成情况

**回答 (A)：**

```sql
SELECT 
    ti.inspector_id AS '检查人员ID',
    ti.inspector_name AS '检查人员姓名',
    COUNT(*) AS '任务总数',
    COUNT(CASE WHEN ti.task_status = 'COMPLETED' THEN 1 END) AS '已完成数',
    COUNT(CASE WHEN ti.task_status IN ('APPROVING', 'COMPLETED') THEN 1 END) AS '统计完成数',
    AVG(ii.score) AS '平均得分'
FROM task_info ti
LEFT JOIN inspect_info ii ON ti.id = ii.task_id 
    AND ii.inspect_type = 'OPS' 
    AND ii.state = 0
WHERE ti.state = 0
    AND ti.inspector_id IS NOT NULL
    AND ti.plan_dt >= '2026-05-01'
    AND ti.plan_dt <= '2026-05-31'
GROUP BY ti.inspector_id, ti.inspector_name
ORDER BY COUNT(*) DESC
```

## 6. 运维单位相关

### 问题 (Q)：统计各运维单位的异常整改及时率

**回答 (A)：**

```sql
SELECT 
    ti.om_id AS '运维单位ID',
    ti.om_name AS '运维单位名称',
    COUNT(ai.id) AS '异常项总数',
    COUNT(CASE WHEN ai.abnormal_status = 'IMPROVED' THEN 1 END) AS '及时整改数',
    COUNT(CASE WHEN ai.abnormal_status = 'OVERDUE_IMPROVE' THEN 1 END) AS '超期整改数',
    ROUND(COUNT(CASE WHEN ai.abnormal_status = 'IMPROVED' THEN 1 END) * 100.0 / NULLIF(COUNT(CASE WHEN ai.abnormal_status IN ('IMPROVED', 'OVERDUE_IMPROVE') THEN 1 END), 0), 2) AS '整改及时率(%)'
FROM abnormal_inspect ai
INNER JOIN task_info ti ON ai.task_id = ti.id 
    AND ti.state = 0
WHERE ai.state = 0
    AND ai.abnormal_status IN ('IMPROVED', 'OVERDUE_IMPROVE', 'CLOSED')
    AND ai.created_dt >= '2026-01-01'
    AND ai.created_dt <= '2026-12-31'
GROUP BY ti.om_id, ti.om_name
ORDER BY COUNT(CASE WHEN ai.abnormal_status = 'IMPROVED' THEN 1 END) * 100.0 / NULLIF(COUNT(CASE WHEN ai.abnormal_status IN ('IMPROVED', 'OVERDUE_IMPROVE') THEN 1 END), 0) DESC
```

## 8. 任务类型相关

### 问题 (Q)：统计不同类型任务的分布情况

**回答 (A)：**

```sql
SELECT 
    ti.task_type AS '任务类型',
    CASE ti.task_type 
        WHEN 'OPS' THEN '现场检查'
        WHEN 'SPECIAL' THEN '专项检查'
        WHEN 'FLIGHT' THEN '飞行检查'
        ELSE '其他' 
    END AS '任务类型名称',
    COUNT(*) AS '任务总数',
    COUNT(CASE WHEN ti.task_status = 'COMPLETED' THEN 1 END) AS '已完成数',
    COUNT(CASE WHEN ti.task_status = 'IN_PROGRESS' THEN 1 END) AS '处理中',
    COUNT(CASE WHEN ti.task_status = 'CLAIMING' THEN 1 END) AS '待认领'
FROM task_info ti
WHERE ti.state = 0
    AND ti.plan_dt >= '2026-01-01'
    AND ti.plan_dt <= '2026-12-31'
GROUP BY ti.task_type
ORDER BY COUNT(*) DESC
```

## 9. 检查项评分相关

### 问题 (Q)：查询现场运维检查单的评分详情

**回答 (A)：**

```sql
SELECT 
    ii.id AS '检查单ID',
    ti.site_name AS '站点名称',
    ops.major_code AS '大类编码',
    ops.major_name AS '大类名称',
    ops.minor_code AS '小类编码',
    ops.minor_name AS '小类名称',
    ops.item_code AS '检查项编码',
    ops.item_name AS '检查项名称',
    ops.item_type AS '检查项类型',
    ops.define_score AS '定义得分',
    ops.actual_score AS '实际得分',
    ops.is_pass AS '是否合格'
FROM ops_inspect_score ops
INNER JOIN inspect_info ii ON ops.inspect_id = ii.id 
    AND ii.state = 0
INNER JOIN task_info ti ON ii.task_id = ti.id 
    AND ti.state = 0
WHERE ops.state = 0
    AND ii.inspect_type = 'OPS'
    AND ti.plan_dt >= '2026-05-01'
    AND ti.plan_dt <= '2026-05-31'
ORDER BY ti.site_name, ops.major_code, ops.minor_code, ops.sort
```

## 10. 参数对比相关

### 问题 (Q)：查询在线设备与便携设备的参数对比结果

**回答 (A)：**

```sql
SELECT 
    ti.id AS '任务ID',
    ti.site_name AS '站点名称',
    prm.major_code AS '大类编码',
    prm.minor_code AS '小类编码',
    prm.item_code AS '检查项编码',
    prm.item_name AS '检查项名称',
    prm.online_val_avg AS '在线值平均值',
    prm.portable_val_avg AS '便携式值平均值',
    prm.abs_error AS '绝对误差',
    prm.rel_error AS '相对误差',
    prm.is_pass AS '是否合格',
    prm.unit AS '单位'
FROM ops_inspect_prm_cmp prm
INNER JOIN inspect_info ii ON prm.inspect_id = ii.id 
    AND ii.state = 0
INNER JOIN task_info ti ON ii.task_id = ti.id 
    AND ti.state = 0
WHERE prm.state = 0
    AND prm.item_type = 'PRM_CMP'
    AND ti.plan_dt >= '2026-05-01'
    AND ti.plan_dt <= '2026-05-31'
ORDER BY ti.site_name, prm.major_code, prm.minor_code
```
